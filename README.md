
# 神主牌位助手 (Ancestral Tablet Assistant)

這是一個專為管理與排版「神主牌位（內外牌）」所設計的單頁式網頁應用程式（Single Page Application）。
本工具旨在協助生命禮儀從業人員、家屬或相關需求者，快速、準確地建立牌位資料，並支援傳統字數吉凶判定、即時預覽、圖片下載及 Excel 匯入/匯出功能。

## ✨ 主要功能

*   **雙模式顯示支援**：可選擇「外牌 + 內牌」完整模式，或針對已有外牌的情況選擇「僅內牌」模式。
*   **即時視覺化預覽**：
    *   **外牌視覺**：模擬木質牌位質感，即時呈現堂號、歲次、主文及奉祀人。
    *   **內牌視覺**：支援白底黑字的內牌木片排版，確保列印與檢視的清晰度。
    *   **總覽模式**：自訂欄數排列，方便一次檢視多片內牌與外牌，利於確認整體版面。
*   **傳統吉凶自動判定**：根據輸入內容自動計算字數，並以傳統「生、老、病、死、苦」進行吉凶標示（吉字顯示綠色，凶字顯示紅色）。
*   **多樣化的內牌格式**：支援 **單人（男/女）**、**夫妻**、**三人**、**四人** 的內牌木片格式，根據不同需求自動調整排版間距與字體大小。
*   **多格式檔案匯出**：
    *   📝 **純文字 (.txt)**：匯出排版好的純文字內容。
    *   📄 **Word (.docx)**：匯出排版好的文件，方便進一步編輯。
    *   📊 **Excel (.xlsx)**：將所有牌位欄位及吉凶判定結構化匯出。
*   **資料保存與還原**：
    *   **Excel 匯入**：支援讀取由本系統匯出的 Excel 檔案，快速還原先前的編輯狀態。
    *   **本地暫存 (Local Storage)**：自動保存當前編輯進度，重新整理頁面資料不遺失。
*   **一鍵下載圖片**：可將外牌、內牌或總覽的預覽畫面，直接下載為高畫質 PNG 圖片。

## 🛠️ 技術架構與依賴

本專案採用純前端技術開發，為單一 HTML 檔案，無需後端伺服器即可運行。

*   **HTML5 / CSS3**：介面佈局與傳統直書排版（使用 `writing-mode: vertical-rl`）。
*   **Vanilla JavaScript (ES6)**：負責邏輯運算、吉凶判定、狀態管理及 DOM 操作。
*   **外部套件 (CDN)**：
    *   [SheetJS (xlsx.full.min.js)](https://sheetjs.com/)：處理 Excel (.xlsx) 檔案的讀取與匯出。
    *   [html-to-image](https://github.com/bubkoo/html-to-image)：將 HTML DOM 元素轉換為 PNG 圖片以下載。

## 🚀 快速開始 (使用方式)

1.  **取得檔案**：下載本專案的 HTML 檔案（例如 `index.html`）。
2.  **開啟工具**：使用任何現代瀏覽器（推薦使用 Google Chrome、Microsoft Edge 或 Firefox）直接雙擊開啟該 HTML 檔案。
3.  **開始編輯**：
    *   在左側「管理資訊」與「外牌設定」填寫基本資料與牌位文字。
    *   點擊「+ 新增內牌木片」來建立內牌，並選擇對應的格式（單人、夫妻等）。
    *   在右側面板即時查看「外牌視覺」、「內牌視覺」或「總覽」。
4.  **下載與匯出**：
    *   確認無誤後，可點選「📷 下載圖片」將畫面存為 PNG。
    *   或切換至「純文字輸出」分頁，將資料存為 TXT, Word 或 Excel 以供後續歸檔。

## ⚠️ 注意事項

*   **字體顯示**：本工具採用「標楷體 (BiauKai / DFKai-SB / Kaiti)」作為主要字體，建議在已安裝該字型的作業系統上使用以獲取最佳預覽效果。
*   **圖片下載限制**：若下載圖片有部分字體被裁切或空白，建議**重新整理頁面**後再試，或確保瀏覽器未阻擋彈出下載視窗。
*   **Excel 匯入**：僅支援由本系統所匯出的 Excel 格式，請勿隨意修改匯出之 Excel 結構再匯入，以免發生讀取錯誤。
